# C/AL to AL

Migration toolkit for Microsoft Dynamics NAV / Business Central: convert C/AL objects to AL, and migrate SQL data between databases — directly from VS Code.

## 🧰 Toolbox


| Tool                    | Purpose                                                                     |
| ----------------------- | --------------------------------------------------------------------------- |
| **C/SIDE Prettier**     | Apply C/AL syntax highlighting.                                             |
| **Conversion Wizard**   | Generate AL extension from standard and customized NAV object.              |
| **Delta Details**       | Compare two NAV object files directly in the VS Code diff editor.           |
| **SQL Explorer**        | Connect to SQL Server, browse databases and preview table data.             |
| **Database Comparison** | Compare two databases; run **Create Database Comparison** to scan and save. |
| **Migration Dashboard** | Run, monitor, and manage data migration with live progress.                 |


> **Quick start (conversion):** Select one or more `.txt` files and/or folders, right-click, and choose **Convert C/AL to AL**. By default, the generated AL objects are saved to `src-cal-to-al/`.
