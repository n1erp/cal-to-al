# Extension assets

Webview HTML, CSS, and JS for Activity Bar toolbox tools. Folder names match `src/toolbox/`.

| Folder | Toolbox tool | Files |
| --- | --- | --- |
| `icons/` | Activity Bar & marketplace | `activity-icon.svg`, `logo.png` (extension icon in `package.json`) |
| `conversion-wizard/` | Conversion Wizard | `wizard.html`, `wizard.css`, `wizard.js` |

TypeScript paths are defined in `src/assetPaths.ts` — update that file when adding or renaming assets.
