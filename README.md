# C/AL to AL

Migration tool for converting Microsoft Dynamics NAV (C/AL) objects to Business Central AL directly from VS Code.

## 🧰 Toolbox

| Tool                  | Purpose                                                                                             |
| --------------------- | --------------------------------------------------------------------------------------------------- |
| **C/SIDE Prettier**   | Apply C/AL syntax highlighting.                                        |
| **Conversion Wizard** | Generate AL extension from standard and customized NAV object. |
| **Delta Details**     | Compare two NAV object files directly in the VS Code diff editor.                            |

> **Quick start:** Select one or more `.txt` files and/or folders, right-click, and choose **Convert C/AL to AL**. By default, the generated AL objects are saved to `src-cal-to-al/`.
